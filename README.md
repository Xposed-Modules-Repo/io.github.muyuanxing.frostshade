# FrostShade

FrostShade 为 ColorOS 15 和 16 的通知中心加入可展开的磨砂堆叠通知，并为控制中心的原有控件加入磨砂效果。两项功能可以分别开启。ColorOS 17 可查看设置和效果演示。

## 安装

1. 安装 [Release](../../releases/latest) 中的签名 APK。
2. 在 LSPosed 中启用 FrostShade，勾选「系统界面」，再重启系统界面或手机。
3. 打开 FrostShade 调整外观。

## 源码与反馈

FrostShade 的自有源码采用 MPL-2.0。项目在 [GitHub](https://github.com/MuYuanXing/FrostShade) 开源。可下载[此版 APK 对应的源码](https://github.com/MuYuanXing/FrostShade/releases/tag/v1.0)，或通过[问题反馈](https://github.com/MuYuanXing/FrostShade/issues)提交复现信息。
